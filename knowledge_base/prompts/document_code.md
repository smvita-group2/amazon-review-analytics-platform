# AI Prompt: Document Code

Use this prompt template when requesting AI assistance to document code:

```markdown
# TASK: Generate Engineering Documentation

Target Component: <FILE_OR_DIRECTORY_PATH>

## Requirements
1. Follow concise engineering documentation style (bullet points, clear tables).
2. Detail Purpose, Responsibilities, Inputs, Outputs, and Dependencies.
3. Keep markdown files under 100 lines.
4. Verify all markdown links and code paths.
```
